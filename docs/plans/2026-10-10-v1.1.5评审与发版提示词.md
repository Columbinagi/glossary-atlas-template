## 备注（给使用者，不用复制进对话）

- **为什么让新会话只做"评审 + 文档 + 发版"**：这三件事是纯文本与 git 操作，**不起浏览器、不产生大输出**，
  零资源风险；而唯一有资源开销的验证已经在你终端里跑完了。
- **新会话开始前**：先把 DSH 应用整个退出再重开（新开对话不会重置渲染进程的内存）。
- **报告文件位置**：`logs/v1.1.5/验证报告.txt`（全文）与 `logs/v1.1.5/summary.json`（摘要）。
  如果新会话读不到，直接把这两个文件的内容贴进对话即可。
- **脚本怎么跑**（Windows PowerShell 5.1 与 PowerShell 7 都行；文件已带 UTF-8 BOM，5.1 不会乱码）：
  ```
  powershell -ExecutionPolicy Bypass -File "E:\ProgramData\GitHubData\Project\词条图鉴模板\logs\v1.1.5\自己跑验证.ps1"
  ```
  跑完屏幕上只有 7 行结论，全文在报告文件里。它**只读本仓库、只在临时目录建净室副本**，不改本仓库任何文件
  （本仓库的 `dist/` 不会被创建）。
- **想撤掉本轮改动**（万一评审不通过）：把 `logs/v1.1.5/before/` 里两个改前副本复制回原位即可，
  GitHub 远端不受影响（仍是 v1.1.4）。
