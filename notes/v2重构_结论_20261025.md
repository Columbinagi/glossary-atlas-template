## 3. 关键改动与理由

1. **详情页去侧栏 + 正文 916 居中**：从结构上消灭「浮标压侧栏」的前提。旧模型 `--fl-right = vw − 正文列 left + 14` 与 28px 空档叠加，重叠 = 浮标宽 − 14（实测 27 / 93 / 119 / **156**）。
2. **浮标纯 CSS 锚定** `calc(50% + 458px + 56px)`，三级退化 1440 / 1240 / 1140；`syncFloatAnchor()` 与 `--fl-right/--fr-left` 删除。
3. **断点按列宽反算**：1440 / 1240 / 1140 / 1100 / 1023 / 900 / 700 / 560；顶栏 ≤1023 两行 108，抽屉/底栏废止。
4. **设计 token**：`#686e79` / `#1b1d21` / 圆角 8+12 / 双层阴影 / `cubic-bezier(.2,.8,.2,1)` / 字号 31·30·24·20·15。
5. **动效 token 化**：`--vt-fade .18s`、`--vt-morph .45s`、`--vt-slide 16vw`、`--vt-dur .3s`、`--vt-enter .32s + .11s`；「先归零再过渡」「起点不可信就不挂 morph」两条判定口径未变。
6. **闸门**：新增 ③-n（浮标不遮挡，红绿双向）；③-i 改直接调 `syncCatActive()`（点芯片重渲会 `scrollTo(0)` 造成假红）；`体检` 的越界判定豁免横向滚动容器内的 chip。
7. **工程线接线**：`拼合` / `校验` 统一 `JC_TEMPLATE`；`体检` 补 `JC_CHROME`。
