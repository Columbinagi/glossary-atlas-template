### F6 · 切语言保留「内容位置」而不只是 scrollY（MEMORY §4 待办）

- **现状**：语言切换走 `preserveScroll`（`:4584` 变量、`:5287` 设值、`paint()` 末尾 `:4715-4717` 恢复），**只恢复 scrollY**；英文重排后「你正在读的那一节」会挪 **129px**（窄屏最多 **342px**，实测见普查结论 §4）。
- **修法（建议设计）**：
  1. 切换时额外**记一个锚点**：从当前视图根（`state.term ? #termView : #topicView`）向下的**子节点索引路径** ＋ 该元素当时的 `getBoundingClientRect().top`；找不到合适元素就不记。
  2. `paint()` 末尾：先按索引路径把同一位置找回来，`scrollTo` 使它的 `top` 与记录值一致；**找不到就退回原来的 scrollY 行为**（这条兜底必须有）。
  3. 为什么用索引路径：中英分册结构是**逐项 1:1 镜像**（派生项目已核验），索引路径跨语言稳定；而元素 id 在派生内容里可能是中文派生值。
- **闸门建议**：新断言「记录某一节的视口 top → 切语言 → 同一节的 top 偏移 ≤ 4px」（而不是断言 scrollY 不变）。先红后绿。

### F7 · 无障碍两项（ACCEPTANCE §三「未列入必修」那条）

## 环境事实与坑（上一轮用真金白银换来的，能省几小时）

1. **`--virtual-time-budget` 下 rAF 只跑一次、scroll 事件不触发**（实测 `ticks=1 / scrollEvents=0`）。所以**挂在 scroll+rAF 上的行为在 `--dump-dom` 闸门里根本不会跑**——要么借「重渲末尾的同步调用」触发（例：`renderTopicView()` 末尾会调 `syncCatActive()`），要么用 `JC_TEMPLATE` 指向改前副本做红绿对照。
2. **`--dump-dom` 取回的 `<title>` 是 HTML 转义的**（hash 里的 `&` → `&amp;`）。`校验.mjs` 已有 `decodeProbeTitle()`，新闸门一律用它解析，否则会把「正确的 `#topic=t1&q=…`」误判成失败（这个坑踩过一次）。
3. **需要侧栏的闸门必须 ≥861px 宽**（≤860 侧栏变抽屉、`#catList` 为 hidden，侦测函数会早退）——`校验.mjs` 里 ③-i 已用 `--window-size=1280,600`。
4. **`paint()` 里抛异常会被 `startViewTransition` 的 `tr.ready.catch` 静默吞掉**：整个 paint 半途而废，而页面看起来正常（实测：`lastRenderedHash` 不再更新 → 「返回来源」失效）。改引擎时**任何 DOM 访问都要判空**；闸门是自己引入这类回归的唯一保险。
5. **可复用探针**在 `logs/morph-返回弹跳复现/`（`probe1`–`probe27`，不进版本库）：访问者 API 探针（逐帧读 `::view-transition-group(x)` 的 transform ＝ 该副本的视口坐标）、参考站解剖探针、手机真触摸探针（`Input.dispatchTouchEvent` + `radiusX/radiusY`）、抽屉分类探针等。新会话可以直接改造复用。
6. 手机/触屏模拟：`Emulation.setDeviceMetricsOverride({mobile:true, deviceScaleFactor:3})` ＋ `setTouchEmulationEnabled` ＋ `setEmitTouchEventsForMouse`；**无头 Chrome 的 `any-pointer: coarse` 恒为 true**（触屏样式一直是生效的）。
