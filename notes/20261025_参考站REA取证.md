# 20261025 参考站 REA 取证（vibe-hub.org）

> **类**：分析 / 论证（**只增不改**）。触发：使用者 20261025 拍板「以 `https://vibe-hub.org/` 为界面与交互基准，用 REA 做证据化逆向，重建 v2 呈现层」。
> **纪律**：只观察公开页面；不登录、不绕过访问控制、不批量抓取；**不复制参考站文案与图片资产**，只提炼布局 / 交互 / 设计规律。
> **产物**：原始件全部落 `logs/20261025-v2取证/`（**不进版本库**）；本文只记观察与判读。

## 0. 结论先行

1. **同源关系已确认**：参考站与 v5 母版是同一套设计语言 —— 品牌色缺省同为 `#3559d8`，View Transition 的 `morph` 组名、`vt-fade-in`、`data-dir` 方向都逐条同名。v5 当年就是从它派生的，所以 v2 的「重建」不是换一套审美，而是**换布局模型与断点推导方式**。
2. **参考站的详情页没有左侧栏**（实测 `side=0px`，单栏居中 916px）。v5 的遮挡 bug 恰恰来自「详情页保留侧栏 + 浮标锚在正文列左缘」这个 v5 自创的组合 —— 参考站里这个组合**不存在**。
3. **参考站的浮标是纯 CSS 锚定**：`right: calc(50% + 514px)`，不量 DOM；三级退化 `1440 / 1240 / 1140`。v5 改成 JS 量 `getBoundingClientRect()`，才引入「宽度随邻居词条名变化」的变量。
4. **参考站的设计规律可搬，实现方式不可搬**：它是 Next.js + 12 份外链 CSS（下载 654,517 B）+ 31 个 script + 外链字体 + GTM；单文件零请求只能承载它的**视觉与几何**，不能承载它的工程形态。
5. **参考站有三处已知缺陷，不照抄**：返回列表 morph 起点在画外、切语言内容位置漂移、分类高亮滞后一格（20261008 实测，见 `notes/20261008_参考站对比实测.md` §3–§5）。这三条我们已有更好的处理，v2 保留。

## 5. v5 遮挡回归的根因证据（复现件：`logs/20261025-预览/词条图鉴-预览.html`）

**现象**：宽屏详情页「上一条」浮标压住左侧目录栏。**复现**：截图 `shots/bug-long-1600.png`、`shots/bug3-long-neighbor-1600.png`。

**实测**（Edge 154，`float-overlap*.json`；短名 = 4–5 字邻居，长名 = 20 字邻居）：

| 视口 | 侧栏 right | 正文列 left | 浮标形态 | 浮标 left…right | 宽 | 重叠 |
|---|---|---|---|---|---|---|
| 1600 | 312 | 340 | 固定 + 文本（6 字邻居） | 193…326 | 133 | **119** |
| 1600 | 312 | 340 | 固定 + 文本（20 字邻居，触顶） | 156…326 | **170** | **156** |
| 1560 | 292 | 320 | 固定 + 文本 | 173…306 | 133 | 119 |
| 1500 | 262 | 290 | 固定 + 文本 | 143…276 | 133 | 119 |
| 1499 | 262 | 290 | 固定 + 仅箭头 | 234…275 | 41 | 28 |
| 1440 / 1366 / 1320 | 232 | 260 | 固定 + 仅箭头 | 205…246 | 41 | 27 |
| 1319 / 1280 / 1100 | 232 | 260 | **静态**（`.entry-nav`） | 260…705 | 445 | 0 |

**根因（不是像素 bug，是定位模型）**：

1. `syncFloatAnchor()`（v5，v1.1.6 时点；搜 `function syncFloatAnchor`）写入
   `--fl-right = vw − detailBody.left + 14` ⇒ 浮标**右缘 = 正文列左缘 − 14px**。
2. 侧栏固定 **208px**，正文列与侧栏之间只有 **28px** 空档（340−312）。
3. 浮标宽度由**邻居词条名**决定：图标态 41、5 字 107、6 字 133、20 字触顶 **170**（`.float-nav` 的 `max-width:170px`）。
4. 于是 **重叠 = 浮标宽 − 14**：41→27、107→93、133→119、170→156。**只要宽度 > 14px 就必然重叠**，与名字长短无关，名字只是放大倍数。
5. 断点也在放大问题：≥1500 才显示文字（`@media (max-width:1499px)` 藏 `.fn-text`）；1320–1499 仅箭头；≤1319 才落回静态行 —— **遮挡区间正好是 1320–∞ 的整个桌面宽屏**。
6. 参考站没有此 bug 的结构原因：**详情页无侧栏 + 锚点用 `50%` 而非量出来的正文列左缘**。

## 7. 参考站的已知缺陷（**不照抄**）

1. **返回列表的 morph 起点在画外**：滚动 900 后返回，副本 y 从 −446 起跳（`notes/20261008_参考站对比实测.md` §3）。v5 的守卫（hero 已滚出视口就不挂 morph）更好，保留。

3. **分类高亮滞后一格**：参考站也复现（同上 §5）。v5 已把阈值与 `scroll-margin-top` 同源（V14），保留。

## 9. 可直接落到 v2 的六条规律

1. **详情页不设常驻侧栏**，正文居中；浮标用 `50%` 锚点而非量 DOM。
2. **浮标三级退化**：文本 → 仅箭头 → 静态行；阈值由「列宽 + 间距」算出，不拍脑袋。
3. **目录页左栏 156px + 28px 间距**；≤1100 收窄到 140/20；侧栏粘顶。
4. **字号强对比**：31/30 → 20 → 15；正文 1.7 行高；字距 `-0.3 ~ -1.1px` 只给大标题。
5. **双层柔和阴影 + 8/12 两级圆角 + `cubic-bezier(.2,.8,.2,1)`**。
6. **顶栏 60 → 1023 以下两行 108**，不做抽屉、不做底栏。
